# Stock Price Analysis

This project compares Ubisoft and Nintendo stock prices using Yahoo Finance data.

## What is included
- `Stock_analyze.py`: script version of the analysis
- `Stock_analyze.ipynb`: notebook version of the analysis

## Setup
Create a virtual environment and install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run the script

```bash
python Stock_analyze.py
```

## Run the notebook

```bash
jupyter notebook Stock_analyze.ipynb
```

## Notes
- Tickers are set to `UBI.PA` (Ubisoft) and `7974.T` (Nintendo).
- Date range defaults to 2018-07-20 through 2025-12-31.
